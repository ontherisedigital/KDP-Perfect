Using this template in Canva
  1. In Canva choose Create a design → Custom size and enter the canvas size shown at the top of this page.
  2. Upload the Template (or the transparent Guides overlay) and stretch it to fill the page.
  3. Lock it, then design inside the green safe areas. Let backgrounds run into the red bleed.
  4. Hide or delete the template before you download. Export as PDF and do not add crop marks or extra bleed, because the canvas already includes it.

Other tools work the same way: create a document at the canvas size, then place the template as a guide layer. Then run the file through Preflight.
